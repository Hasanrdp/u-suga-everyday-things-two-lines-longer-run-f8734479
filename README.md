# The School Hallway Jam

A two-line explanation of an everyday thing for the
[make.fun Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479)
bounty.

## The entry

> A traffic jam is a hallway full of kids trying to leave school through one door at the same time.
> It maps everyone crowding toward one narrow exit so nobody moves faster than the person ahead, but leaves out that cars cannot squeeze sideways the way kids can.

## How it works

`main.py` (Python 3.13, standard library only) writes those two lines — 259
characters, inside the 1–400 character gate — to `/output/entry.txt`. No
network, no randomness, no input: every run writes the exact same bytes, and
the program reads the file back afterwards to prove it matches.

## Why this entry

Six original candidates were pre-judged pairwise, in both orders, against
the judge brief published in the kit, plus two field patterns (the toaster
sunbed and the rain sponge) as benchmarks. The exact judge model
(z-ai/glm-5.3-flash on OpenRouter) was unreachable — the account's purchased
credits are exhausted (HTTP 402, about $0.0001 left) — so the rounds ran on a
free proxy model (gemini-3.5-flash-lite). The school-hallway traffic jam led
the first round-robin (0.564 mean game score), then beat the wet-dog rain
entry head-to-head (0.60) and the toaster-sunbed benchmark decisively. The
hallway is something every 10-year-old has stood in, the bottleneck maps
exactly onto how a jam forms, and the second line names the one way the
picture breaks — cars cannot squeeze sideways the way kids can.
